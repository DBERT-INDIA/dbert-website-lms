## 1. How to Build a Hybrid RAG Retrieval Pipeline

Basic RAG tutorials embed a PDF into a vector store and call `top_k=4`. In production, that fails on exact identifiers (like `CERT-DBERT-2026-DA-057`, error codes, or Indian statutory clauses).

### The 3-Stage Hybrid Retrieval Flow
1. **Sparse Search (BM25 / Postgres `tsvector`):** Captures exact keyword and ID matches.
2. **Dense Vector Search (`pgvector` / Qdrant):** Captures semantic intent and paraphrased queries.
3. **Reciprocal Rank Fusion (RRF) + Reranking:** Merges both candidate lists using:

```python
def reciprocal_rank_fusion(bm25_ids: list[str], vector_ids: list[str], k: int = 60) -> list[str]:
    scores: dict[str, float] = {}
    for rank, doc_id in enumerate(bm25_ids):
        scores[doc_id] = scores.get(doc_id, 0.0) + 1.0 / (k + rank + 1)
    for rank, doc_id in enumerate(vector_ids):
        scores[doc_id] = scores.get(doc_id, 0.0) + 1.0 / (k + rank + 1)
    return [doc_id for doc_id, _ in sorted(scores.items(), key=lambda x: x[1], reverse=True)]
```

Pair this with a cross-encoder reranker on the top 15 fused chunks before passing the top 4–5 chunks to your LLM context window.

## 2. How to Architect Multi-Tenant SaaS APIs Safely

In multi-tenant SaaS, a single missed `WHERE tenant_id = $1` clause causes a cross-customer data breach.

- **Extract `tenant_id` from verified JWT/session context**, never from an untrusted request body or query parameter.
- **Enable PostgreSQL Row-Level Security (RLS)** on shared tables so the database engine itself enforces tenant isolation:

```sql
ALTER TABLE project_documents ENABLE ROW LEVEL SECURITY;

CREATE POLICY tenant_isolation_policy ON project_documents
  USING (tenant_id = current_setting('app.current_tenant_id')::uuid);
```

- **Index composite keys `(tenant_id, created_at DESC)`** so tenant dashboards remain fast under concurrent load.

## 3. How to Harden JWT, OAuth2 & OWASP Security

Every authentication PR reviewed by DBERT mentors is audited against a strict security checklist:

- **JWT Hygiene:** Keep access tokens short-lived (15 minutes), store refresh tokens in `HttpOnly`, `Secure`, `SameSite=Lax` cookies, and implement token family revocation on reuse detection.
- **OAuth2 PKCE:** Always validate the cryptographic `state` parameter to prevent login CSRF, and use PKCE (`code_verifier` / `code_challenge`) for public or SPA clients.
- **OWASP Top 10 Guardrails:**
  - **Broken Object-Level Authorization (BOLA):** Verify resource ownership on every `GET / PATCH / DELETE` route.
  - **Rate Limiting:** Apply sliding-window rate limits (e.g., Redis) on `/login`, `/otp`, and `/api/enroll/*` endpoints.
  - **Input Validation:** Enforce strict Zod or Pydantic schemas at the API boundary.
